# Adaptive Ticket Auctions

COMSCI/ECON 206 Problem Set 2

## Research Question

How should a ticket platform allocate limited concert tickets when genuine fans and scalpers can learn the platform rules and strategically adapt their behavior?

## Mechanisms

We compare:

1. Standard second-price sealed-bid auction
2. Verified second-price auction using account-history or verification information

## Main Metrics

- Genuine-fan allocation rate
- Scalper win rate
- Allocation efficiency
- Platform revenue

## Computational Method

We use Python simulation in Google Colab.

Main libraries:

- NumPy
- pandas
- Matplotlib

The simulation does not require a GPU.

## Reproducibility

The main notebook is:

`auction_simulation.ipynb`

A fixed random seed will be used where relevant so that results can be reproduced.
